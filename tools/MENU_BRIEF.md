# Bottom-menu brief — tab by tab

**Goal:** the bottom menu shows only where you choose where to go next. Everywhere you are *doing* something (learning, reading, practising, looking something up), it tucks away and a small arrow at the bottom brings it back.

**Rule**
- **Menu shown — hubs and lists:** the four tab home screens and the lists you pick from.
- **Menu tucked — everything else:** a page reached from a hub that has a back button and one job. This includes detail pages (a word, a verb, a grammar topic), settings, progress, and forms.
- New pages default to **tucked**: only the hub list shows the menu, so a new screen can't accidentally get it.
- Every tucked page must still have a way out: the header back button and the arrow. Opening the menu from the arrow never covers the reading player or Profe.
- Profe's chat always tucks it.

**Tab by tab**

| Tab | Shown (hubs/lists) | Tucked (task/detail) |
|---|---|---|
| Today | Today home, Hoy (today's plan) | Settings, Progress, Quick drill |
| Course | Course home, level pages (A1…C2, My school), level exam list | Units, flashcards for a level, vocabulary by theme, mock test, exam guide, full exam overview and papers, level test, My mistakes |
| Practice | Practice home, Flashcards (deck list), Listen list, Read list, Write list, all-exams hub | Every text, a deck being studied, a writing task, add-your-own-text form |
| Library | Library home, Verbs list, Grammar hub, Guides list, 7,000 words list, Resources | A verb, reflexive verbs page, a grammar topic, a guide, a word page |

**Done when**
- An automated walk through every route (each tab, each kind of page) matches the table.
- Every tucked page shows the arrow and has a back button; the arrow opens and closes the menu; moving to another page tucks it again; the earlier tests still pass.
